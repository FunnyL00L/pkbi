# 🌐 Portal Informasi PKBI Kabupaten Buleleng

Portal informasi interaktif untuk mendukung pelayanan,
edukasi, dan akses informasi kesehatan masyarakat.

## 📌 Fitur Utama

| Fitur | Deskripsi |
|---|---|

| 🏡 Desa Binaan | Profil Desa Binaan Sari Mekar |
| 📊 Grafik Stunting | Visualisasi data stunting |
| 💍 Skrining Catin | Layanan skrining calon pengantin |
