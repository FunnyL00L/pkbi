# 🌐 Portal Informasi PKBI Kabupaten Buleleng

**Perkumpulan Keluarga Berencana Indonesia (PKBI)**
Kabupaten Buleleng, Bali.

Portal informasi interaktif untuk mendukung pelayanan,
edukasi, dan akses informasi kesehatan masyarakat.

## 🔗 Akses Portal

[![Buka Portal](https://img.shields.io/badge/🌐_Buka_Portal-PKBI_Buleleng-00897B?style=for-the-badge)](https://username.github.io/nama-repository/)

## 📌 Fitur Utama

- 🗺️ Peta interaktif 9 kecamatan berbasis Leaflet.
- 🏡 Profil Desa Binaan Sari Mekar.
- 📊 Visualisasi data dan grafik stunting.
- 💍 Layanan skrining calon pengantin (Catin).
- 💬 Chat konsultasi anonim.
- 🩺 Edukasi kesehatan reproduksi dan IMS.
